# Obsidian settings worth setting

Not enforced by anything — a checklist for first open.

- **Files & Links → Default location for new attachments** → `attachments/`
- **Editor → Show line numbers** → on, helps when an agent cites a line
- **Appearance → Show inline title** → on
- Core plugins: Graph view, Backlinks, Outline
- Community plugin worth considering: Excalidraw, for `derive` submissions
  without leaving the vault

Obsidian's own `.obsidian/` config directory is gitignored by default in this
template — settings are per-machine and syncing them causes more pain than it
saves.
