# Attachments

Where Obsidian puts images. Set it so:
**Settings → Files & Links → Default location for new attachments →
`attachments/`**.

You should rarely need to come in here by hand. `derive` submissions arrive
because you attached a photo to a *note*, and Obsidian filed the image here
while embedding it there. The note is the record; this directory is storage.

## The loop

```
agent writes  notes/.../derive-007.md
you           open it, attach your photo under "## Attempt"
              (desktop: paste or drag. mobile: tap attach, take the photo.)
you           say "done" in the session
agent         reads the embed, appends grading to the same note
```

Mobile is the short version of this loop, and it needs the vault synced to your
phone — Obsidian Sync, Syncthing, or self-hosted LiveSync. Still open; see
`docs/OPEN.md`.

Webcam or other host-device capture is declined, not pending: `docs/OPEN.md`
decision 3.
